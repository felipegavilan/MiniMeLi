# 🛒 MiniMeLi - E-Commerce .NET MAUI

Aplicación móvil desarrollada como proyecto académico para la Tecnicatura de Desarrollo de Software de la Universidad Nacional de Formosa (UNaF), simulando las funcionalidades principales de un mercado libre simplificado mediante .NET MAUI y C#.

## 🚀 Tecnologías y Herramientas
- **Framework:** .NET MAUI
- **Lenguaje:** C# / XAML
- **IDE:** Visual Studio
- **Control de Versiones:** Git & GitHub
- **Gestión de Tareas:** Trello
